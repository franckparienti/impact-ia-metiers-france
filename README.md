# Impact de l'IA sur les metiers en France (2026)

Jeu de donnees open data synthetisant les etudes publiques sur l'impact de l'intelligence artificielle sur les metiers et l'emploi en France, avec les besoins en formation associes.

## Contenu

Le fichier `impact-ia-metiers.csv` contient par secteur :
- Secteur NAF (nomenclature INSEE)
- Nombre d'emplois concernes
- Taux d'exposition a l'automatisation IA (source : France Strategie, OCDE)
- Metiers les plus impactes
- Competences IA prioritaires a developper
- Type de formation recommandee (sensibilisation, operationnelle, expertise)

## Sources

- France Strategie, "Intelligence artificielle et travail" (2024)
- OCDE, "AI and the Future of Skills" (2025)
- DARES, "Les metiers en 2030" (2022)
- Retours terrain de 200+ accompagnements par BusinessDigital.fr
